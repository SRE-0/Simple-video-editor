# Contribuir

Abre una incidencia con el navegador, sistema operativo, pasos de reproducción y resultado esperado. No adjuntes grabaciones privadas ni claves.

Mantén el orden de carga descrito en `docs/ARCHITECTURE.md`, los controles accesibles por teclado y las alternativas opacas de los materiales. Ejecuta `npm run check` y `npm run build`. Para cambios en medios, comprueba manualmente sincronización, búsqueda, recorte y el archivo exportado en los navegadores afectados. Documenta los límites de los códecs que encuentres.
